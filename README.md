# EpicCO: Glass Cutting

The solver that [EpicCO](https://github.com/ZHANG-NI/EpicCO) produced for the glass cutting problem of the ROADEF/EURO Challenge 2018, starting from MBA* (L. Libralesso and F. Fontan, European Journal of Operational Research, 2021; https://github.com/fontanf/roadef2018).

## Run

```
mkdir -p bin
bash build.sh bin
bin/solver <instance> <solution> -t <seconds> -seed <seed>
```
